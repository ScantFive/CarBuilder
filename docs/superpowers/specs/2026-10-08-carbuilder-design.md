# CarBuilder — спецификация

Дата: 2026-10-08

## Цель

Браузерное приложение, в котором пользователь в 3D собирает каркас гоночной машины
(узлы и балки), расставляет на нём колёса и двигатель, затем нажимает «Тест» и ездит
на этой машине по 3D-трассе (WASD). Поведение машины реалистично зависит от
конструкции: масса, центр масс, расположение колёс, какие колёса ведущие и рулевые.
Трасса берётся из файла (исходник — SVG схемы Yas Marina, конвертируется в JSON).

Критерии успеха:
- Можно собрать машину с нуля или изменить шаблонную и проехать на ней по трассе.
- Разные конструкции ощутимо по-разному едут (передний/задний привод, база, масса).
- Стены по краям трассы не дают выехать за её пределы.
- Работает секундомер круга, сохранение машин, сброс по R.

## Стек

| Задача | Технология |
|---|---|
| Язык / сборка | TypeScript (strict), Vite |
| 3D-рендер | Three.js |
| Физика | Rapier3D (`@dimforge/rapier3d-compat`), `DynamicRayCastVehicleController` |
| UI | Обычный HTML/CSS, без фреймворка |
| Юнит-тесты | Vitest |
| E2E смоук-тест | Playwright (Chromium) |
| Конвертер трассы | Node-скрипт на TS (`tsx`), запускается вручную |

## Архитектура

```
src/
  main.ts                 — точка входа, переключение экранов editor <-> test drive
  model/
    car.ts                — типы CarDesign (Node, Beam, Wheel, Engine), шаблон, (де)сериализация
    validate.ts           — валидация конструкции -> список ошибок
    physicsProps.ts       — масса, центр масс, роли колёс (pure-функции)
  editor/
    Editor.ts             — 3D-сцена редактора, камера, режимы, ввод
    history.ts            — undo-стек (снимки CarDesign)
    symmetry.ts           — зеркалирование операций по оси X
    panel.ts              — HTML-панель: режимы, свойства колеса, высота плоскости, сохранение
  track/
    trackData.ts          — типы TrackData, загрузка/проверка JSON
    trackGeometry.ts      — построение кромок, асфальта, стен из осевой линии (pure + three)
    laps.ts               — чекпоинты, логика круга, секундомер (pure)
  sim/
    TestDrive.ts          — сцена заезда: мир Rapier, трасса, машина, камера, цикл
    vehicle.ts            — CarDesign -> тело Rapier + vehicle controller + меши
    input.ts              — клавиатура (WASD, Space, R, Esc)
    hud.ts                — спидометр, время круга, лучший круг, подсказки
  storage/
    carStorage.ts         — localStorage + экспорт/импорт .json
tools/
  svg-to-track.ts         — SVG -> tracks/*.json
tracks/
  source/yas-marina.svg   — исходная схема
  yas-marina.json         — сгенерированная трасса (коммитится)
tests/                    — юнит-тесты Vitest
e2e/                      — смоук-тест Playwright
```

Каждая pure-часть (model/*, track/laps.ts, расчёты геометрии трассы) не зависит от
Three.js/Rapier и покрывается юнит-тестами.

## Модель данных машины

Система координат: метры, +Y вверх, +Z — вперёд по машине, +X — вправо.

```ts
interface CarDesign {
  version: 1;
  name: string;
  nodes: { id: string; x: number; y: number; z: number }[];
  beams: { id: string; a: string; b: string }[];          // a, b — id узлов
  wheels: { id: string; node: string; radius: number;      // радиус 0.2..0.6 м
            steering: boolean; driven: boolean }[];
  engine: { node: string } | null;
}
```

- Колесо и двигатель крепятся к узлу. На одном узле не больше одного колеса.
- Двигатель не может стоять на узле с колесом (иначе нет смысла в точке).
- Ограничения редактора: узлы в пределах |x| ≤ 1.5, 0 ≤ y ≤ 1.5, |z| ≤ 3 (м).

### Валидация (перед «Тест»)

Ошибки (блокируют тест), каждая — понятное сообщение на русском:
- колёс меньше 3 или больше 8;
- нет двигателя;
- нет ни одного ведущего колеса;
- нет ни одного рулевого колеса;
- каркас несвязный (узлы с колёсами/двигателем не соединены балками в одну компоненту);
- колёса лежат на одной прямой в плане (XZ) — машина опрокинется;
- балок нет.

### Физические свойства (pure)

- Балка: масса = длина × 8 кг/м. Двигатель: 150 кг в его узле. Колесо: 10 кг в узле.
- Центр масс — взвешенное среднее (балки — по своей середине).
- Тензор инерции — сумма точечных масс (балка — 3 точки: концы и середина), Rapier
  получает массу/ЦМ/инерцию через `setAdditionalMassProperties`, коллайдеры
  имеют нулевую плотность.
- Роли колёс задаёт пользователь (флажки). Значения по умолчанию при постановке колеса:
  рулевое = колесо впереди ЦМ (z > ЦМ.z); ведущее = колесо в той половине машины
  (перед/зад), где двигатель; если двигатель в пределах ±0.3 м от ЦМ по z — все ведущие.
- Рулевое колесо позади ЦМ поворачивается в обратную сторону.

## Редактор (3D)

- Сцена Three.js: сетка-пол, рабочая плоскость (полупрозрачная сетка) на высоте h,
  h меняется ползунком или клавишами Q/E шагом 0.1 м (0..1.5).
- Камера: OrbitControls (правая кнопка — вращение, колесо — зум, средняя — панорама).
- Режимы (кнопки на панели + горячие клавиши 1–6):
  1. **Узел** — клик по рабочей плоскости ставит узел (привязка к сетке 0.1 м).
  2. **Балка** — клик по узлу, затем по второму; повторная балка не создаётся.
  3. **Колесо** — клик по узлу ставит/выделяет колесо; на панели — радиус, «рулевое»,
     «ведущее».
  4. **Двигатель** — клик по узлу переносит двигатель туда.
  5. **Перемещение** — перетаскивание узла в плоскости XZ; с Shift — по Y.
  6. **Удаление** — клик по узлу (удаляет его, балки, колесо/двигатель на нём) или балке.
- **Симметрия X** (вкл. по умолчанию): создание узла с x≠0 создаёт зеркальный узел;
  балка между узлами создаёт зеркальную балку, если у концов есть зеркальные пары;
  колесо — зеркальное колесо с теми же свойствами; перемещение и удаление
  зеркалятся. Узлы с |x| < 0.05 считаются центральными (без пары).
- Ctrl+Z / Ctrl+Shift+Z — отмена/повтор (снимки CarDesign, до 100 шагов).
- Отображение: узлы — сферы, балки — цилиндры, колёса — цилиндры заданного радиуса
  (рулевые — синие, ведущие — оранжевые обода, оба — двухцветные), двигатель — красный
  куб, ЦМ — маркер.
- Панель: имя машины, список ошибок валидации (обновляется вживую), кнопки
  «Тест», «Новая», «Шаблон», «Сохранить», список сохранённых, «Экспорт», «Импорт».
- При первом запуске загружается шаблон: прямоугольная рама 1.8×4 м, 4 колеса r=0.35,
  передние рулевые, задние ведущие, двигатель сзади.

## Трасса

### Конвертер `tools/svg-to-track.ts`

Вход: `tracks/source/yas-marina.svg`. Выход: `tracks/yas-marina.json`.

1. Найти путь дороги: путь с наибольшим числом точек среди чёрных заливок (в данном
   файле — `class="fil2"`); можно переопределить аргументом `--road-class`.
2. Распарсить `d` (M/m, L/l, C/c, Z/z и т. п.) в полилинии (кривые — дискретизация).
   Контур дороги — кольцо: внешний и внутренний подпути (или один подпуть, если
   окажется иначе — тогда осевая линия ищется растеризацией и скелетизацией).
3. Осевая линия: для каждой точки равномерно передискретизированной внешней кромки
   взять середину между ней и ближайшей точкой внутренней кромки; сгладить и
   передискретизировать с шагом ~5 м после масштабирования.
4. Старт: центр клетчатых `rect` → ближайший индекс осевой линии. Направление
   движения — по белому полигону-стрелке (`fil6`): порядок точек осевой линии
   разворачивается так, чтобы шёл по стрелке.
5. Масштаб: длина замкнутой осевой линии = 5281 м. Ось Y SVG → ось Z мира (с отражением,
   чтобы трасса не была зеркальной).

Формат JSON:

```json
{
  "name": "Yas Marina",
  "width": 14,
  "closed": true,
  "points": [[x, z], ...],
  "startIndex": 0
}
```

`points` упорядочены по направлению движения, `startIndex` после конвертации = 0.

### Геометрия в игре

- Кромки: смещение осевой линии на ±width/2 по нормали (с защитой от самопересечений
  в шпильках — сглаживание нормалей).
- Асфальт — лента треугольников; трава — большая плоскость под трассой; линия
  старта — клетчатая полоса.
- Стены: высота 1 м, вдоль обеих кромок; коллайдеры — `cuboid` на каждый сегмент
  (с небольшим перекрытием) — фиксированные тела Rapier. Пол — один `cuboid`.

## Заезд (Test drive)

- Машина ставится на старт, носом по направлению трассы, колёса над асфальтом.
- Корпус: одно динамическое тело, коллайдеры — капсулы по балкам (радиус 0.05 м) +
  куб двигателя + шар на каждом колёсном узле (чтобы корпус не проваливался).
- Колёса: `DynamicRayCastVehicleController`, точка крепления — узел колеса,
  ход подвески 0.3 м, жёсткость/демпфирование масштабируются от массы на колесо,
  сцепление `frictionSlip` ≈ 2.5.
- Двигатель: суммарная сила 9000 Н при 0 км/ч, линейно падает до 0 к 300 км/ч;
  делится поровну между ведущими колёсами.
- Тормоз: S при движении вперёд; при скорости < 1 км/ч S включает задний ход (30% силы).
- Ручник: Пробел — сильное торможение колёс, не являющихся рулевыми (если все рулевые —
  на всех).
- Руль: A/D, макс. угол 30°, плавное нарастание, уменьшение угла с ростом скорости
  (до 10° на 200 км/ч).
- R — сброс: машина ставится на последний пройденный чекпоинт, носом по трассе, скорость 0.
- Esc / кнопка «В редактор» — возврат в редактор, конструкция сохраняется.
- Камера: позади и выше машины, плавно следует (lerp), смотрит на машину.
- Шаг физики фиксированный 1/60 с с накоплением времени.

## Круг и HUD

- Чекпоинты: осевая линия делится на 20 равных участков. Прогресс машины = индекс
  ближайшей точки осевой линии. Чекпоинт k засчитан, если пройдены все предыдущие.
- Машина появляется на линии старта; таймер первого круга запускается с первым
  нажатием W. Круг засчитывается при возврате к старту после всех 20 чекпоинтов,
  после чего сразу начинается следующий.
- HUD: скорость (км/ч), текущий круг, последний, лучший (лучший хранится в localStorage
  по имени машины), подсказка по клавишам.

## Сохранение машин

- localStorage, ключ `carbuilder.cars` — словарь имя → CarDesign.
- Экспорт — скачивание `<имя>.car.json`; импорт — выбор файла, проверка `version` и
  структуры; при ошибке — сообщение, текущая машина не меняется.
- Последняя редактируемая машина автоматически сохраняется в `carbuilder.current`.

## Обработка ошибок

- Ошибка загрузки трассы или инициализации Rapier/WebGL — экран с сообщением.
- Невалидная машина — кнопка «Тест» показывает список ошибок, заезд не начинается.
- Машина перевернулась/застряла — подсказка «R — сброс» в HUD, если скорость < 1 км/ч
  дольше 3 с или машина перевёрнута.

## Тестирование

- Vitest: validate.ts, physicsProps.ts (масса, ЦМ, роли по умолчанию), symmetry.ts,
  history.ts, carStorage (сериализация), laps.ts, конвертер (парсер path, осевая линия
  на синтетическом кольце, масштаб), trackGeometry (кромки на ширине width).
- Playwright смоук: открыть страницу → шаблон валиден → «Тест» → держать W 2 с →
  скорость в HUD > 0 → Esc → редактор.
- Ручная проверка: проехать круг на шаблоне и на машине с передним приводом.

## Вне рамок первой версии

Повреждения, звук, AI-соперники, несколько трасс в UI (формат это позволяет),
мобильное управление, мультиплеер, вертикальный профиль трассы.
