# Кузов автомобиля — спецификация

Дата: 2026-10-09. Дополняет `2026-10-08-carbuilder-design.md`.

## Цель

Отдельное окно редактора, в котором пользователь собирает кузов машины из готовых
деталей и расставляет на нём точки крепления. В редакторе каркаса точки крепления
соединяются балками с узлами каркаса. Кузов добавляет массу и участвует в столкновениях.

Критерии успеха:
- Из окна каркаса можно открыть окно «Кузов», собрать кузов, вернуться и прикрепить его.
- Кузов виден в редакторе каркаса и в заезде, движется вместе с машиной.
- Тяжёлый кузов заметно меняет массу и центр масс; кузов бьётся о стены.
- Старые файлы машин (version 1) открываются без ошибок.

## Модель данных

Формат машины становится `version: 2`.

```ts
type BodyShape = 'box' | 'wedge' | 'cylinder' | 'sphere' | 'wing';

interface BodyPart {
  id: string;
  shape: BodyShape;
  position: Vec3;                       // центр детали, координаты машины, м
  rotation: Vec3;                       // углы Эйлера XYZ, градусы
  size: Vec3;                           // габариты по осям детали, м
  color: string;                        // '#rrggbb'
}

interface BodyMount { id: string; x: number; y: number; z: number }  // координаты машины

interface BodyDesign { parts: BodyPart[]; mounts: BodyMount[] }

interface CarDesign {            // изменения относительно version 1
  version: 2;
  body: BodyDesign | null;
  // nodes, beams, wheels, engine — как раньше
}
```

- Кузов редактируется прямо в координатах машины — отдельного смещения нет.
- **Балка** может соединять узел с узлом, узел с точкой крепления или точку с точкой
  (поля `a`/`b` ссылаются на id узла или точки крепления; id уникальны в машине).
- Колёса и двигатель ставятся только на узлы.
- `parseCar` принимает version 1 (добавляет `body: null`, ставит `version: 2`) и version 2.
  Проверки: ссылки балок на узлы/точки, размеры и цвет деталей, известная форма.

### Формы деталей

Размер `size = (sx, sy, sz)` задаёт габариты по осям детали до поворота.

| Форма | Геометрия | Коллайдер |
|---|---|---|
| `box` — панель | параллелепипед sx×sy×sz | `cuboid` |
| `wedge` — клин | треугольная призма: сечение в плоскости YZ — прямоугольный треугольник с катетами sz (низ) и sy (задняя стенка, z = −sz/2); вытянута по X на sx | `convexHull` вершин |
| `cylinder` — цилиндр | ось по X длиной sx, сечение — эллипс sy×sz (16 сегментов) | `convexHull` вершин |
| `sphere` — сфера | эллипсоид с осями sx, sy, sz | `convexHull` вершин (сетка 8×6) |
| `wing` — крыло | плоскость sx×sy×sz плюс две вертикальные шайбы на концах (толщина 0.02, высота 3·sy+0.1, длина sz) | `cuboid` основной плоскости |

Ограничения: каждая сторона 0.02..4 м; центр детали в пределах |x| ≤ 1.6, 0 ≤ y ≤ 2,
|z| ≤ 3.5; не больше 60 деталей и 16 точек крепления.

Размеры новых деталей по умолчанию: box 1×0.05×1, wedge 1×0.4×0.8, cylinder 0.6×0.3×0.3,
sphere 0.5×0.5×0.5, wing 1.6×0.04×0.4. Новая деталь появляется в (0, 0.6, 0), цвет #d33a2c.

## Физика

- Масса детали = площадь поверхности × **6 кг/м²** (тонкая оболочка). Площадь:
  box `2(sx·sy + sy·sz + sx·sz)`; wedge `sy·sz + sx·(sy + sz + √(sy²+sz²))`;
  cylinder `sx·π(a+b) + 2πab` с a = sy/2, b = sz/2 (периметр эллипса ≈ π(a+b));
  sphere — формула Томсена `4π((aᵖbᵖ + aᵖcᵖ + bᵖcᵖ)/3)^(1/p)`, p = 1.6075, полуоси a, b, c;
  wing — площадь плиты как у box плюс две шайбы по `2·h·sz`, h = 3·sy + 0.1.
- Деталь — точечная масса в своём центре; входит в `computeMassProperties`
  (масса, центр масс, инерция).
- Балки к точкам крепления весят как обычные (8 кг/м).
- В заезде каждая деталь — коллайдер на корпусе машины (плотность 0, масса через
  `setAdditionalMassProperties`), трение 0.3. Кузов абсолютно жёсткий.
- Вершины деталей для коллайдеров и габаритов считает pure-функция
  `partVertices(part): Vec3[]` (без Three.js).

## Проверка конструкции — новые ошибки

- `"Кузов не прикреплён к каркасу"` — у кузова есть детали, но ни одна точка крепления
  не соединена балками с компонентой каркаса, где стоят колёса и двигатель.
  (Кузов без деталей и точек не проверяется.)
- `"Кузов ниже колёс — заденет землю"` — минимальная y по вершинам деталей ниже
  `min(узел.y − радиус − 0.3)` по колёсам (низ колеса при подвеске в покое).
- `"Слишком много деталей кузова (максимум 60)"`, `"Слишком много точек крепления (максимум 16)"`.

## Окно «Кузов»

- Кнопка **«Кузов»** в панели редактора каркаса открывает экран кузова; кнопка
  **«Готово»** (или Esc без выделения) возвращает в каркас. Изменения сразу пишутся в
  текущую машину (с автосохранением), отмена общая для экрана кузова.
- Сцена: та же сетка-пол и стрелка «ПЕРЕД»; каркас машины (узлы, балки, колёса, двигатель)
  показан полупрозрачным и не кликается.
- Камера: OrbitControls как в редакторе каркаса.
- Панель (`data-testid`):
  - `body-add-<shape>` — пять кнопок добавления детали;
  - `body-mode-select`, `body-mode-mount` — режимы «Выбор» и «Крепления» (клавиши 1, 2);
  - `body-mirror` — симметрия слева/справа (вкл. по умолчанию);
  - `body-undo`, `body-redo`;
  - блок выбранной детали `body-part`: поля `part-px/py/pz`, `part-rx/ry/rz`,
    `part-sx/sy/sz` (числа), `part-color` (color input), кнопки `part-gizmo-move`,
    `part-gizmo-rotate`, `part-gizmo-scale` (клавиши G, R, S), `part-duplicate`, `part-delete`
    (Delete);
  - `body-stats` — «Деталей N · креплений M · масса кузова X кг»;
  - `body-done`.
- Режим «Выбор»: клик по детали выделяет её и показывает `TransformControls`
  (перемещение / поворот / масштаб). Перетаскивание гизмо меняет деталь; запись в историю —
  по отпусканию. Привязка: перемещение 0.05 м, поворот 5°, масштаб — к сотым.
- Режим «Крепления»: клик по поверхности детали ставит точку крепления (жёлтый ромб) в
  точку попадания луча (округление 0.01 м); клик по существующей точке удаляет её
  вместе с балками к ней.
- Симметрия: для детали с |x| ≥ 0.05 создаётся/правится/удаляется зеркальная пара
  (x → −x, поворот: ry → −ry, rz → −rz); для точки крепления — то же.
  Пара определяется по совпадению зеркальной позиции (допуск 0.01) и формы.

## Кузов в редакторе каркаса

- Детали кузова показаны полупрозрачными (opacity 0.35) и не кликаются; переключатель
  `show-body` скрывает их.
- Точки крепления — жёлтые ромбы, их можно выбирать инструментом «Балка» (как узлы) и
  удалять балки к ним инструментом «Удаление». Перемещать/удалять сами точки здесь нельзя.
- Симметрия балок работает и для точек крепления (зеркальная пара точек).

## Заезд

- Детали кузова рисуются непрозрачными, точки крепления не показываются.
- Коллайдеры деталей добавляются к телу машины. Высота спавна прежняя (по колёсам).

## Хранение

Кузов хранится внутри машины и сохраняется/экспортируется вместе с ней. Отдельной
библиотеки кузовов нет. Шаблонная машина остаётся без кузова.

## Тестирование

- Vitest:
  - `parseCar`: version 1 → `body: null`, `version: 2`; балка к точке крепления
    проходит, к несуществующей — ошибка; неизвестная форма — ошибка.
  - `partArea`/`partVertices`: площадь коробки 1×1×1 = 6; клин — 6 вершин; габариты
    повёрнутой на 90° по Y коробки 2×1×1 → по X ширина 1.
  - `computeMassProperties`: коробка 1×1×1 добавляет 36 кг; центр масс смещается к ней.
  - `validateCar`: кузов без креплений → ошибка; прикреплённый балкой → нет ошибки;
    деталь ниже колёс → ошибка.
  - операции кузова: добавление/дублирование/удаление с симметрией; удаление точки
    крепления удаляет её балки; зеркальная балка узел↔точка.
- Playwright: открыть «Кузов» → добавить коробку → режим «Крепления» → клик по детали →
  «Готово» → инструмент «Балка»: точка → узел → ошибок нет → «Тест» → скорость > 0.
