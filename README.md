# CarBuilder

Браузерный 3D-конструктор гоночной машины. Собираете каркас из узлов и балок, ставите колёса
и двигатель, жмёте **«Тест»** и едете по трассе Yas Marina на WASD. Масса, центр масс,
расположение колёс, привод и рулевые колёса вычисляются из конструкции — разные машины
едут по-разному.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm run dev        # http://localhost:5173
```

Другие команды:

| Команда | Что делает |
|---|---|
| `npm test` | юнит-тесты (Vitest) |
| `npm run e2e` | смоук-тест в браузере (Playwright) |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run track -- <in.svg> <out.json>` | конвертация схемы трассы в JSON |

## Редактор

| Действие | Как |
|---|---|
| Вращать камеру | правая кнопка мыши |
| Приблизить | колесо мыши |
| Сдвинуть камеру | средняя кнопка мыши |
| Инструменты | кнопки на панели или клавиши 1–6 |
| Высота рабочей плоскости | ползунок или Q/E (шаг 0.1 м) |
| Отменить / повторить | Ctrl+Z / Ctrl+Shift+Z |

Инструменты:

1. **Узел** — клик по рабочей плоскости (сетка 0.1 м).
2. **Балка** — клик по двум узлам; следующий клик продолжает цепочку. Esc — сбросить.
3. **Колесо** — клик по узлу ставит/выбирает колесо; на панели — радиус (0.2–0.6 м),
   «рулевое» (синий диск) и «ведущее» (оранжевый диск).
4. **Двигатель** — клик по узлу переносит двигатель (он один).
5. **Перемещение** — тяните узел по плоскости, с Shift — по высоте.
6. **Удаление** — клик по узлу, балке, колесу или двигателю.

**Симметрия** (включена по умолчанию) зеркалит все действия слева направо.
Зелёная стрелка «ПЕРЕД» показывает нос машины. Жёлтый ромб — центр масс.

Перед тестом конструкция проверяется: 3–8 колёс, один двигатель, есть ведущие и рулевые
колёса, всё соединено балками, колёса не на одной линии.

Машины сохраняются в браузере («Сохранить»/«Открыть») и в файл («Экспорт»/«Импорт»).
Текущая машина сохраняется автоматически.

### Физика

- Балка — 8 кг/м, двигатель — 150 кг, колесо — 10 кг; центр масс и инерция считаются по ним.
- Двигатель: 9000 Н с места, падает до нуля к 300 км/ч, делится между ведущими колёсами.
- Рулевые колёса позади центра масс поворачивают в обратную сторону.
- Колёса — подвеска на лучах (Rapier `DynamicRayCastVehicleController`).

## Заезд

| Клавиша | Действие |
|---|---|
| W | газ |
| S | тормоз, после остановки — задний ход |
| A / D | руль |
| Пробел | ручник |
| R | сброс на последний пройденный чекпоинт |
| Esc | назад в редактор |

Секундомер стартует с первого нажатия W. Круг засчитывается, только если пройдены все
20 чекпоинтов по порядку. Лучший круг запоминается для каждой машины.

## Трасса

Трасса хранится в `tracks/yas-marina.json`:

```json
{ "name": "Yas Marina", "width": 14, "closed": true, "points": [[x, z], ...], "startIndex": 0 }
```

`points` — осевая линия в метрах по направлению движения, `width` — ширина полотна.
Края, асфальт и стены строятся из неё автоматически.

JSON получен из схемы `tracks/source/yas-marina.svg`:

```bash
npm run track -- tracks/source/yas-marina.svg tracks/yas-marina.json
```

Конвертер берёт контур дороги (путь `class="fil2"` из двух кромок; другой класс —
`--road-class`), линию старта по клетчатым `rect`, направление — по белой стрелке
(`polygon class="fil6"`), и масштабирует круг до `--length` метров (по умолчанию 5281).
